# News Hybrid

Изолированный модуль сигнала для международного перевода. Он объединяет
историю дневных курсов ЦБ и структурированные новостные события, применяет
редкий причинный отбор и сам формирует заголовок и текст пуша.

В пакет включена финальная версия `L5_NEWS_Q85`, а не прежняя ценовая B1.
Восемь моделей соответствуют последовательным тестовым полугодиям
2023–2026. Текущая модель действует до 01.01.2027; после этой даты модуль
возвращает `model_outside_validity`, а не использует устаревшую модель.

## Что принимает модуль

- направление: AMD, KGS, KZT, TJS или UZS;
- текущий официальный курс в RUB за единицу валюты;
- 14 признаков истории курса;
- независимые новости, известные к моменту решения;
- постоянный `event_id` для защиты от повторной отправки.

Историю курса можно превратить в 14 признаков функцией `build_features`.
Для этого нужны ряды целевой валюты и контрольных USD/EUR/CNY. Новости
передаются в нормализованном виде: тип, время доступности, применимость к
рублю/получателю/миру и фактическое действие ставки, если оно известно.
Свободный текст автоматически не классифицируется.

## Установка и проверка

```bash
python -m pip install ./news_hybrid
python -m pip install "./news_hybrid[test]"
python -m pytest -c news_hybrid/pyproject.toml news_hybrid/tests
```

Исполнение использует только стандартную библиотеку Python. Модель
экспортирована в проверяемый JSON, `pickle` и `joblib` в пакете отсутствуют.

## Подключение из Python

```python
from news_hybrid import decide

result = decide(request_payload, state_path="state/news-hybrid.sqlite3")
if result["status"] == "READY":
    push = result["notification"]
    save_for_delivery(push["notification_id"], push["title"], push["body"])
```

SQLite-файл нужно сохранять между запусками и использовать совместно всеми
worker одного сервиса. В нём находятся состояние нового эпизода, недельный
лимит и результаты обработанных `event_id`.

JSON-интерфейс:

```bash
news-hybrid request.json --state state/news-hybrid.sqlite3
```

Полный контракт и схема подключения находятся в [INTEGRATION.md](INTEGRATION.md),
метрики и ограничения — в [METRICS.md](METRICS.md).

## Правило сигнала

Модель оценивает каждую новую дневную публикацию. Низкий score подготавливает
состояние; следующий высокий эпизод расходуется сразу. Сигнал появляется,
только если за предшествующие 14 дней есть релевантная новость. Максимум два
сигнала на валюту за московскую ISO-неделю. Фиксированной паузы между пушами
нет. Q85 — квантиль исторических calibration scores, а не 85% уверенности.

Модуль не отправляет пуш напрямую и не выбирает получателей. Он возвращает
готовый payload, который сервис команды сохраняет и доставляет.
