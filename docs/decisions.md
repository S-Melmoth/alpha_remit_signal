# Журнал решений

Здесь записываются только решения, которые уже приняты. Варианты будущей модели до обсуждения сюда не добавляются.

## Принято

### Данные

- Базовый источник — дневные официальные курсы ЦБ РФ с 2010 года.
- Каноническое значение — `rub_per_unit`: рублей за одну единицу иностранной валюты.
- Используются только опубликованные наблюдения; выходные и праздники не заполняются.
- Кризисные периоды и реальные скачки не удаляются вручную.
- Снижение `rub_per_unit` выгодно отправителю рублей.

### Методология

- Любой признак на дату T должен использовать только данные, доступные на T.
- Итоговая проверка моделей должна быть walk-forward.
- Текущий ноутбук предназначен для EDA, а не считается готовым модельным pipeline.
- Симметричный wavelet-анализ остаётся исследовательской визуализацией.

### Структура проекта

- Исходное условие хранится в `docs/case.md`.
- Текущая постановка — в `docs/experiment_spec.md`.
- Текстовый EDA-отчёт и папка `reports/` удалены как дублирующие ноутбук и summary CSV.

## Пока не решено

- Определение target и горизонт оценки.
- Конкретные признаки и модели.
- Схема walk-forward-разбиения.
- Пороги, cooldown и объединение индикаторов в сигнальный поток.
- Основная метрика выбора модели помимо обязательного сравнения со случайным днём.
