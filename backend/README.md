# Прототип трансграничного перевода

В репозитории также есть [набор Go-сервисов](behaviour/README.md): поведенческий анализ, Pusher с общим недельным лимитом и приоритетами, API истории платежа и Payment Scheduler. Они используют общую PostgreSQL и таблицы `global_notifications`, `completed_push`, `scheduled_cis_payments`.

Мобильный интерактивный прототип по `transfer-by-phone-number_RUS.pdf`. Изображения и иконки извлечены из исходного PDF; элементы интерфейса реализованы в HTML/CSS, формы и переходы — на JavaScript.

## Запуск

Нужен Node.js 18 или новее. Установка зависимостей не требуется.

```sh
npm run dev
```

Открыть http://localhost:5173 — главная страница «Ближе, чем кажется» в красно-белой стилистике Альфа-Банка. Кнопки «Попробовать» открывают выбор из пяти умных сценариев и обычного перевода. У каждого сценария есть отдельная страница с живым прототипом телефона, режимами Product/Tech и синтетическими таблицами. Обычный сценарий находится на http://localhost:5173/payments. На телефоне в той же сети можно открыть `http://<IP компьютера>:5173`.

Главная адаптирована для мобильных экранов, поддерживает переключение направления на иллюстрации и отключает анимацию при `prefers-reduced-motion`. Композиция объёмных карточек и наклон при движении курсора адаптированы из [Credit Card Hero, ruixen.ui](https://21st.dev/@ruixen.ui/components/credit-card-hero), а сетка возможностей — из [Bento Grid, designali-in](https://21st.dev/@designali-in/components/bento-grid), полученных через MCP 21st.dev. Реализация — локальные HTML/CSS/JavaScript, дополнительных зависимостей и запросов к 21st.dev из браузера нет.

На странице `/payments` на компьютере показываются корпус телефона, навигация по восьми шагам и сравнение с исходными изображениями; на телефоне приложение занимает экран целиком.

## Интерактивные фичи

Все пять страниц `/features/*` встраивают сам `/payments` в телефон через iframe. Используются одни формы, клавиатура, выбор страны и банка, проверка перевода, результат и история. Переключение Product/Tech сохраняет текущий экран и ввод пользователя.

- В поведенческом сценарии переключите наличие поступления и попадание во временное окно, затем нажмите «Вызвать поведенческий пуш». Повторное уведомление по тому же паттерну и уведомление после выполненного перевода блокируются.
- В новостном и рекомендательном сценариях кнопка создаёт синтетический ML-сигнал. «Проверить приоритеты» добавляет оба глобальных сигнала и выполняет один цикл Pusher: behaviour → history → news. За московскую календарную неделю доступно два слота. «Следующая неделя» переносит демовремя и требует нового поступления для поведенческого пуша.
- Пуш появляется поверх оригинального приложенного скриншота (`public/assets/push-home-screen.png`). Нажатие открывает предзаполненную форму перевода. Кнопки «Экран телефона» и «Открыть банк» переключают фон и приложение.
- Плитка «Повторить платёж» заполняет форму данными прошлой операции. Сумму, телефон, страну, банк и назначение можно изменить обычными элементами `/payments`.
- После подходящего повторного перевода можно задать еженедельное или ежемесячное расписание, проверить его и подтвердить в отдельном окне. В «Моих платежах» доступны список, детали, изменение суммы/даты/времени/получателя и отмена. На обычном `/payments` предложение доступно после любого демоперевода.
- Tech показывает путь текущего действия и таблицы, которые обновляются после отправки пуша, перевода и изменения расписания. Счётчики Product вычисляются из текущего демо.

Это локальная симуляция сервисов в браузере, без вызовов Go API. Состояние каждого сценария изолировано в localStorage; стартовые данные — два еженедельных перевода по 16 000 ₽ и баланс 83 500,35 ₽. «Сбросить демо» восстанавливает эти данные. Реальные пуши и списания не выполняются. Серверная реализация Pusher и Scheduler описана отдельно в `behaviour/README.md`.

## Сценарий

1. Платежи → Переводы за рубеж.
2. Прокрутить список или найти Таджикистан через поиск.
3. Выбрать «По номеру телефона через СБП».
4. Нажать «Укажите номер получателя», ввести `+7 926 577-51-28` или выбрать номер из PDF, затем «Продолжить».
5. Выбрать «Душанбе Сити Банк».
6. Выбрать «Безвозмездный перевод на текущие расходы».
7. Ввести 500 ₽ с экранной или физической клавиатуры, нажать стрелку.
8. Проверить реквизиты и нажать «Перевести».

После отправки доступны результат, скачивание текстовой демоквитанции и история. Баланс и операции сохраняются в localStorage браузера. В разделе «Главный» можно восстановить баланс, подтвердив очистку истории. «Начать заново» сбрасывает только текущую форму.

## Границы прототипа

Реальные переводы не выполняются; подключения к банку, авторизации и проверки существования получателя нет. Получатель — демонстрационный персонаж из PDF. Комиссия фиксирована: 30 ₽ внутри суммы списания. Для Таджикистана воспроизведён пример: 500 ₽ → 51,65 TJS при курсе 9,1 ₽/TJS. Для Беларуси, Кыргызстана и Узбекистана используются явно обозначенные условные курсы. Лимиты 100–100 000 ₽ — демонстрационные.

Все восемь экранов восстановлены по PDF. Ввод телефона, экран успеха, история и вспомогательные состояния дополняют сценарий, поскольку их нет в документе. Второстепенные банковские разделы открывают пояснение, а не имитируют реальные услуги. Исходный PDF и изображения доступны локально, внешних сетевых запросов нет.

## Проверка

```sh
npm test
```

Проверяются расчёт из PDF, комиссии, остаток, лимиты, нормализация номера и расчёты для четырёх стран, а также условия пуша, приоритеты, дедупликация и смена календарной недели.

Сквозная браузерная проверка находится в `tests/browser.mjs`. При работающем сервере её можно запустить с установленными Playwright и Chromium:

```sh
node tests/browser.mjs /absolute/path/to/playwright /absolute/path/to/chromium
node tests/landing.mjs /absolute/path/to/playwright /absolute/path/to/chromium
```

Она проходит весь сценарий, проверяет четыре страны, ошибки ввода, сохранение истории после перезагрузки, скачивание квитанции, сброс демобаланса, сравнение с PDF и экраны 390×844 и 320×568. Скриншоты проверки сохраняются в `reference/verification/`.

Проверка Landing, пяти кликабельных Product/Tech-страниц, вызова пушей на исходном фоне, перехода в перевод, создания/редактирования/отмены расписания, сохранения данных и адаптации на 960/600/390/320 пикселях:

```sh
node tests/features.mjs /absolute/path/to/playwright /absolute/path/to/chromium
```
